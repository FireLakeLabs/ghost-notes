# Ghost Notes shell

The header exposes transport, undo/redo, Paste, Copy, Settings and About.
The reference timeline stays above the whole-program draft; G85 owns their
relationship until section links reach the interface. Settings are session-only.
The timeline's existing settings host moves into the dialog without cloning
controls. The owning modules retain their state; there is no persistent settings
store.

The manifest opens the app in a standalone window from the browser's install
action. The SVG and 192/512 PNG icons are original geometric recording lines
and arrangement marks. No service worker or offline music cache is registered.
Opening files still uses the local reference adapter and G48's optional retained
folder handle. Installing is not saving: copy the arrangement to keep it.

The browser install test uses Chromium's Page.getAppManifest and
Page.getInstallabilityErrors against a built app, decodes both PNG sizes,
and checks that no worker or CacheStorage entry exists. The measured result
is zero installability errors and standalone display. The native operating
system's install menu/window was not automated.

The test also checks 25 text/surface pairs from the actual CSS tokens:
cream text, muted text, recording blue, arrangement cream and difference orange
on canvas, panel, button, hover and active surfaces. Minimum contrast is 4.6707:1,
above WCAG AA's 4.5:1 for ordinary text. This token check does not audit every
editor's fixed colors or every composited pixel. Some editor drawings retain
legacy accent/selection colors; that palette work is a follow-up on #11.

The shell, copy panel, settings and complete About notice were inspected in
screenshots using only the invented fixture. About lists all eight pinned
Strudel/superdough packages, including soundfonts 1.3.0, with source links and
the deployed commit link; the hosting wave owns its drift test.
