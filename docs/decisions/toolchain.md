# Decisions: code and toolchain (G33–G34)

How the code was brought in and built. The index is [decisions](../decisions.md).

- **G33 (2026-11-13) ODM's corpus comes in whole.** Its 13 `real-*`
  programs were generated by AI, so the owner confirms there is no licence
  issue; corpus/README.md's note that collection "does not assert a
  third-party licence" refers to that. 44 tests use them.
- **G34 (2026-11-13) Toolchain: TypeScript 7 and Oxlint.** TypeScript 7.0's
  native compiler type-checks (0.36 s against 2.7 s for 5.9). Its package has
  no classic JavaScript API, so Oxlint replaces ESLint and typescript-eslint
  (the same recommended rules, migrated by `@oxlint/migrate`; `no-undef` is
  left to TypeScript), and the boundary check parses with `oxc-parser`. Vite
  8 (Rolldown), Vitest 5 (up to 8 local workers, 2 in CI), Prettier 3.10,
  Playwright 1.65. acorn 8.19 now sits under the pinned Strudel. Node stays
  24.22.2; Strudel stays pinned.
- **G35 (2026-11-13) Decisions are an index plus topic files.** The single
  decisions page reached 1,285 of its 1,500-word budget with the plan's later
  steps still to decide. The budget keeps the page every agent reads short, so
  it stays, and the page became an index of one line per decision. Full
  entries moved unchanged into topic files under `docs/decisions/`, each with
  its own 1,500-word budget, checked by `npm run check:docs`.
